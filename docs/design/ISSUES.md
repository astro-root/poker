# デザイン課題と対応状況

最終更新: 2026-10-22（Poker Colosseum リデザイン）

## 方針

参考サイト（quiznavi.astro-root.com / nopo1.com / astro-root.pages.dev）に共通する「ほぼ黒の背景、細い罫線、番号付きの一覧、1色のアクセント」を土台に、**コロッセオ（闘技場）**の世界観を重ねた。

- 背景 `#09090b`、アクセントはゴールド `#d9ae4a`（1色）、危険色は赤。茶色の太い枠と段付き影は廃止し、細い縁取りとやわらかい影に統一。
- フォントは Noto Sans JP（`@fontsource-variable/noto-sans-jp` でセルフホスト）。本文16px、補助14px、英字の装飾ラベルのみ12px。
- 色・文字サイズ・角丸・影は `:root` のCSS変数に集約。

## 旧デザインの課題 → 現状

| # | 課題 | 状態 |
| --- | --- | --- |
| 1 | 文字が小さい（8〜11px） | 解消。`--text-sm: 14px` / `--text-md: 16px` を基準に |
| 2 | 勝率表示が詰まる・カードに重なる | 解消。「勝率」「引き分け」をラベルと数値に分けたチップ表示 |
| 3 | モバイルの卓が窮屈・席が不揃い | 解消。相手席は等サイズの固定グリッド（1〜7人対応） |
| 4 | 固定高・`overflow: hidden` によるクリップ | 解消。`dvh` とフレキシブルレイアウト。`max-height` の場当たり対応は横向きスマホ専用の1箇所のみ |
| 5 | 操作領域の密度・画面下固定でない | 解消。スマホは手札＋操作を `sticky; bottom: 0`（safe-area対応）、PCは右サイドの固定パネル |
| 6 | 配色と枠の古さ | 解消。ダーク基調に統一 |
| 7 | 状態別スクリーンショット未取得 | 取得（`docs/design/screenshots/`、`?mock=` フィクスチャ使用） |
| 8 | 手札が席カードに埋もれて読めない（A-1） | 解消。手札は独立した大きな要素（最小 52×73px（横向きスマホ）、通常 56〜64px幅、PC 78×110px） |
| 9 | 座席ラベルの重なり | 解消。状態ラベルは席カード内に収め、ディーラーボタンはヘッダー行に配置 |
| 10 | フォールドが無料でできてしまう | 解消。チェック可能な場面ではフォールドボタンを出さず、エンジンでも拒否 |

## 画面サイズ別の挙動

- **820px以上**: 左に卓、右に「手札＋操作」の固定サイドパネル。卓の幅が640px以上なら席を楕円に配置し、自分は常に手前（下）。
- **820px未満**: 卓は上部、手札＋操作は画面下に固定。相手席は固定グリッド。
- **横向きスマホ（高さ520px以下）**: サイドパネルを圧縮し、手札と全アクションを同一画面に表示。
